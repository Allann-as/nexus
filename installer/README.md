# Instalador do NEXUS

Instalador pronto do NEXUS para **Windows (x64)** — não precisa compilar nada.

## Como instalar
1. Baixe **`NEXUS-Setup-v1.3.0.exe`** (nesta pasta — no GitHub, clique no arquivo e depois em **Download**).
2. Execute o `.exe`.
3. O Windows SmartScreen pode avisar **"editor desconhecido"** (o instalador não é assinado): clique em **Mais informações → Executar assim mesmo**.
4. No primeiro acesso, crie uma senha de 6 dígitos e diga como quer ser chamado.

## Bom saber
- **100% offline** — os dados ficam só neste computador (`%APPDATA%\Nexus`), sem nuvem nem conta.
- Instalar em outra máquina começa **vazio** (os dados não viajam pelo GitHub).
- Alternativa oficial: a aba **[Releases](../../releases/tag/v1.3.0)** tem este mesmo `.exe` e também o `.msi`.

> Versão do instalador: **v1.3.0**. Ao publicar uma versão nova, substitua o `.exe` desta pasta e atualize este número.
